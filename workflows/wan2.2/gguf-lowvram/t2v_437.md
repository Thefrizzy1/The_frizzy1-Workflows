## How to use (Wan 2.2 T2V 14B, GGUF low VRAM)

**What it does:** a prompt -> a short video. Wan 2.2 14B text-to-video as two Q2_K GGUF experts (high noise first, then low noise) with the lightx2v speed LoRA, then RealESRGAN x2, a resize, RIFE and an MP4.

**Inputs**
1. **Positive prompt**: the scene, the motion and the camera.
2. **Negative prompt**: what to avoid (also used by NAG).

**Models and Loras** group: two GGUF loaders (high noise top, low noise below), one lightx2v T2V LoRA per expert (strength 1), T5 text encoder, VAE `wan_2.1_vae`.

**Important settings**
- **EmptyHunyuanLatentVideo**: 480 x 848 (width x height), 57 frames. This sets the video size and length (more = more VRAM and time).
- **Pass1 High Noise / Pass2 Low Noise** (Asymmetric Tiled KSampler): seed 8918 fixed, 4 steps, cfg 1, lcm / simple. Pass 2 denoise 0.3 refines pass 1; the creator suggests 0.3 to 0.5.
- **enhancments 2 passes** group (one row per expert): Enhance-A-Video 1.0, CFG-Zero* init, shift 6 (ModelSamplingSD3), NAG scale 11 / tau 0.25 / alpha 2.373 (NAG uses the negative prompt).
- **Without the LoRA**: bypass both LoRA loaders, then cfg 6 and 30 to 60 steps on both samplers (creator advice).
- **Purge VRAM** hangs off the pass 1 output to free VRAM once pass 1 is done (its output is not wired, so the run order is up to ComfyUI).
- **Upscaler and 2nd frame interpolaration** group: RealESRGAN x2, then Lanczos to 1080 x 1920 (portrait), then RIFE (multiplier 1 = no new frames; 2 doubles the frame count).
- **Export**: MP4 h264, 24 fps, crf 19, ping-pong on (plays forward then back). Lands in `ComfyUI/output/` with the prefix `AnimateDiff`.

Then **Run**.

**Tips**
- 14B needs BOTH GGUFs (high + low noise) and the **wan_2.1_vae**. The Wan 2.2 VAE is for the 5B model only; the wrong VAE gives black or garbled frames.
- The T5 text encoder runs on the CPU (CLIPLoader device `cpu`) to save VRAM.
- Out of memory: fewer frames, a smaller size, or a smaller tile on VAE Decode (Tiled).
- Landscape video: swap width and height, and set Image Scale to 1920 x 1080.
- Wan wants 4n+1 frames (for example 33 or 81).
- The 5B TI2V graphs are in `source/` (`Wan2.2- 5B T2V.json`, `Wan2.2- 5B I2V.json`); they use the Wan 2.2 VAE.

Faster attention: start ComfyUI with --use-sage-attention (less VRAM). --use-ck-attention changes the image for the same seed.

_Tested on: RTX 3050 Laptop 4 GB (creator). Checked on ComfyUI 0.45.3: the graph converts; not run there yet._
